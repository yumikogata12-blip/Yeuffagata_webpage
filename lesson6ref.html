Lesson 2 — Reflection

This lesson taught me how CSS can be used to set the dimensions of HTML elements and control their appearance on a webpage. I learned about properties like width, height, min-width, max-width, and line-height, and how they help define the size and spacing of headings, paragraphs, images, and other elements. Understanding how to set dimensions precisely makes layouts more consistent and visually appealing across different devices and screen sizes.

I also explored pseudo-classes, which allow elements to change style based on their state. For example, the :link pseudo-class targets hyperlinks that have not yet been visited, letting me style them differently from visited links or links that are hovered over. Combining dimension properties with pseudo-classes makes it possible to create interactive and dynamic designs while keeping the page structure clean and organized.

Finally, I realized that controlling dimensions and using pseudo-classes together helps create responsive and user-friendly web pages. By applying the right size properties and styling elements based on their state, I can make websites that not only look good but also provide a better user experience. This lesson gave me a solid foundation for designing layouts that are both functional and visually appealing.
